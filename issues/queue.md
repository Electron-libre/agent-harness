# Issue queue

Open issues in the order to work on them: the first is the next one. Read by `just next-issue`;
`just close-issue` removes a line, `skill:create-issue` inserts one at its rank, `skill:prioritize-issues`
re-ranks the whole list. Line format: `- [<file stem>](<file stem>.md) - <why here>`.

- [resolve_the_instruction_files_as_a_session_loads_them](resolve_the_instruction_files_as_a_session_loads_them.md) - after the always-on rules in the audit: completes what it lists, and fixes the imports `fixed-context` counts
- [list_the_user_level_instruction_files_in_the_audit](list_the_user_level_instruction_files_in_the_audit.md) - after the files of the projects: the last instruction files the audit misses; small, before the evaluation issues
- [record_a_verdict_for_each_harness_change](record_a_verdict_for_each_harness_change.md) - low priority, last: applies the evidence rules of the first and reads the metrics of the report
- [measure_the_effect_of_the_language_hint](measure_the_effect_of_the_language_hint.md) - last: needs sessions run with the hook before it can measure anything
